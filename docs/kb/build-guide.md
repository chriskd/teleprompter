### DIY Beam Splitter Alternative
Instead of buying 70/30 teleprompter glass, you can make one:
1. Buy 8x10" picture frame glass ($3-5 at dollar store)
2. Apply 30% window tint film ($8-10 for a roll)
3. Result: Functional 70/30-ish beam splitter

**Note:** This won't be as optically perfect as real teleprompter glass, but works for basic use.

## Assembly Guide (Build A: Desview T3)

### Total Time: ~30-45 minutes (first time) / ~10-15 minutes (experienced)

---

### Phase 1: Software Setup (20-30 minutes)

> **Do this first!** Test your Pi + display before mounting in the housing.

#### Step 1.1: Flash Raspberry Pi OS (~5-10 min)

1. Download [Raspberry Pi Imager](https://www.raspberrypi.com/software/) on your computer
2. Insert MicroSD card into your computer
3. In Imager, select:
   - **Device:** Raspberry Pi Zero 2 W
   - **OS:** Raspberry Pi OS Lite (64-bit) — under "Raspberry Pi OS (other)"
   - **Storage:** Your MicroSD card
4. Click the **gear icon** for advanced settings:
   - Set hostname: `teleprompter`
   - Set username/password (write these down!)
   - Configure WiFi (your network name + password)
   - Enable SSH with password authentication
5. Click **Write** and wait for completion

#### Step 1.2: First Boot Test (~5 min)

1. Insert SD card into Pi Zero 2W
2. Connect Mini-HDMI cable to Pi and display
3. Power the display via USB
4. Power the Pi via micro-USB (use a good 5V/2.5A+ supply)
5. Wait 60-90 seconds for boot
6. You should see the Pi OS command line on the display

> **Checkpoint:** If you see text on the display, your hardware works!

#### Step 1.3: Install Teleprompter Software (~10 min)

SSH into your Pi and install your teleprompter app. See [software-setup.md](software-setup.md) for detailed instructions.

---

### Phase 2: Hardware Assembly (10-15 minutes)

#### Step 2.1: Prepare Components (~2 min)

Lay out all components:
- [ ] Desview T3 housing (folded)
- [ ] Pi Zero 2W with SD card inserted
- [ ] 7" display
- [ ] Mini-HDMI to HDMI cable
- [ ] USB power cables (2x)
- [ ] Lens adapter ring for your camera

#### Step 2.2: Unfold Desview T3 (~1 min)

1. Open the carry case
2. Unfold the T3 frame — it clicks into position
3. Slide the beam splitter glass into the top slot
4. Glass should sit at ~45° angle

#### Step 2.3: Mount Display + Pi (~3 min)

1. Place the 7" display face-down in the tablet holder area
2. The display faces DOWN toward the glass (text reflects UP to your eyes)
3. Position the Pi Zero 2W behind the display
4. Route cables neatly to avoid blocking the camera view

#### Step 2.4: Connect Cables (~2 min)

```
┌─────────────────────────────────────────────┐
│                WIRING DIAGRAM               │
├─────────────────────────────────────────────┤
│                                             │
│   [USB Power] ──→ [Pi Zero 2W micro-USB]    │
│                          │                  │
│                    [mini-HDMI]              │
│                          │                  │
│                          ▼                  │
│                    [HDMI cable]             │
│                          │                  │
│                          ▼                  │
│   [USB Power] ──→ [7" Display HDMI + USB]   │
│                                             │
│   Optional:                                 │
│   [USB Foot Pedal] ──→ [Pi via OTG adapter] │
│                                             │
└─────────────────────────────────────────────┘
```

#### Step 2.5: Attach to Camera (~2 min)

1. Find the lens adapter ring matching your lens diameter (49-82mm included)
2. Screw the adapter ring onto your camera lens
3. Slide the Desview T3 onto the adapter ring
4. Tighten the locking mechanism

#### Step 2.6: Final Adjustments (~2 min)

1. Power on the Pi and display
2. Launch your teleprompter app
3. Adjust the glass angle until text is readable at eye level
4. Check that camera can see through the glass clearly
5. Text should appear right-reading in the reflection (mirrored in software)

---

### Phase 3: Test Your Setup (~5 min)

1. **Eye contact test:** Look at the camera lens while reading text — the reflection should align
2. **Focus test:** Can your camera focus on subjects behind the glass?
3. **Lighting test:** Check for glare or reflections on the glass
4. **Scroll test:** Practice with foot pedal or remote control

## Common Mistakes to Avoid

| Mistake | Problem | Solution |
|---------|---------|----------|
| **Display faces wrong way** | Text doesn't reflect to your eyes | Display must face DOWN toward the glass, not up |
| **Text not mirrored** | Text appears backwards in reflection | Enable mirror mode in your teleprompter software |
| **Weak power supply** | Pi freezes, display flickers | Use quality 5V/3A supply, avoid cheap cables |
| **Glass at wrong angle** | Text too high/low in your view | Adjust glass to ~45°, fine-tune for your eye level |
| **Cables in camera view** | Black cables visible in shot | Route cables behind display, use cable clips |
| **Direct sunlight** | Glare makes text unreadable | Use in shade or indoors, add hood if needed |
| **Pi overheating** | Freezes during long recordings | Add heatsink to Pi, ensure airflow |
| **Wrong HDMI port** | No display output on Pi Zero | Use the port labeled "HDMI" not "USB" |

## Wiring Reference

### Minimum Setup (2 cables)
```
Power Source → USB-A to Micro-USB → Pi Zero 2W
Pi Zero 2W → Mini-HDMI to HDMI → Display (also powers display via HDMI 5V)
```

### Recommended Setup (3 cables)
```
Power Source → USB-A to Micro-USB → Pi Zero 2W
Power Source → USB-A to Micro-USB → Display (dedicated power)
Pi Zero 2W → Mini-HDMI to HDMI → Display
```

### Full Setup with Foot Pedal (4 cables)
```
Power Source → USB-A to Micro-USB → Pi Zero 2W
Power Source → USB-A to Micro-USB → Display
Pi Zero 2W → Mini-HDMI to HDMI → Display
Foot Pedal → USB-A to Micro-USB OTG → Pi Zero 2W
```

> **Note:** Pi Zero 2W only has one micro-USB data port. For foot pedal, you need a micro-USB OTG adapter or hub.
