### What's Actually Included
- Prompter unit with 9" display
- Beam splitter glass (70/30)
- Universal camera bracket
- Lens adapter rings (49-82mm)
- Facecam Pro backplate only (not Facecam MK.2)

### What You'll Probably Need to Buy
- **Foot pedal** ($89.99) - No hands-free control without this
- **Phone grip** ($14.99) - If you use iPhone as your camera
- **Desk mount** ($49.99) - The included bracket is basic

## Elgato Known Issues (Avoided in DIY)

<!-- IMAGE NEEDED: Screenshot of Elgato Camera Hub software interface -->
**[Photo placeholder: Camera Hub software interface]**

### Hardware Limitations
- **No true power-off** — Display stays on while USB connected; Elgato has shown screenshots of a fix but hasn't released it
- **Low resolution screen** (1024x600) — Limits usefulness as a camera monitor; problematic for 4K workflows where you'd need 2-4x zoom
- **Computer required** — Cannot operate standalone; must be tethered to Mac/PC at all times
- **Plastic build quality** — "Almost exclusively black plastic, which sometimes seems more and sometimes less robust" ([TweakTown](https://www.tweaktown.com/reviews/10607/elgato-prompter-game-changer-for-content-creators/index.html))

### Missing Features (Extra Cost)
- **No foot pedal** — Stream Deck Pedal is $89.99 extra
- **No iPhone support out of box** — Phone Grip is $14.99 extra
- **Wrong camera backplate** — Includes Facecam Pro plate but not Facecam MK.2 (the more common model)

### Software Issues
- Camera Hub software described as "lacking next to the hardware"
- Voice Sync requires NVIDIA RTX 2060+ or Apple M1+ chip
- Chapter navigation is clunky compared to custom solutions

## When Elgato Might Be Worth It

- You need tight Stream Deck integration
- You want plug-and-play with no assembly
- Budget is not a concern
- You prefer commercial support/warranty

---

## When DIY Is Better

- You want to save $290-370 (vs realistic Elgato setup)
- You want foot pedal control included from day one
- You need standalone operation (no computer tethering)
- You want unlimited software customization
- You have a 3D printer for custom housing
- You value higher resolution displays (up to 1280x800)
